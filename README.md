# PROJECT NOVA

PROJECT NOVA is a personal, non-commercial Minecraft Java Edition launcher currently under development.

## Features

- Minecraft version and profile management
- Realistic graphics presets
- Shader and resource-pack integration
- Mod management
- Performance optimization
- Planned in-game customization and HUD features

## Authentication

PROJECT NOVA is being developed to use official Microsoft authentication and Minecraft ownership verification.

The project does not attempt to bypass Minecraft authentication or licensing requirements.

## Development Status

PROJECT NOVA is currently in private development and testing. The launcher source code and executable are not publicly distributed.

This repository provides public information about the project.
